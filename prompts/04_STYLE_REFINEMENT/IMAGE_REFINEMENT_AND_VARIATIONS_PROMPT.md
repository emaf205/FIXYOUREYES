# STYLE REFINEMENT & VARIATIONS PROMPT

## Objective
Use this prompt to iterate on a generated thumbnail, adjust contrast, change framing, swap color palettes, or enhance typography legibility.

---

## The Prompt (Copy & Paste)

```markdown
Review the thumbnail image generated in the previous step. We need to refine and elevate this thumbnail for maximum clarity and CTR on mobile.

Apply the following targeted adjustments:

1. MOBILE CONTRAST CHECK:
   - Increase the luminance contrast between the foreground subject and background elements.
   - Deepen shadows and punch up highlights so the silhouette reads clearly at 15% scale.

2. TYPOGRAPHY ENHANCEMENT:
   - Make the headline text cleaner, bolder, and more intentional.
   - Ensure the text does not bleed into noisy background patterns. Add subtle drop shadow or backdrop separation if needed.
   - Verify that the bottom-right corner remains completely free of text or key faces (YouTube duration badge safe zone).

3. VARIATION OPTIONS (Generate 2 distinct alternatives):
   - Variant A (Minimalist Shift): Strip away unnecessary secondary clutter, focusing purely on 1 subject + 1 punchy headline.
   - Variant B (Atmospheric Shift): Adjust the color grading (e.g. shift from cool cyan/blue to warm amber/crimson) while keeping the same core layout.

Refine the image now while strictly maintaining 16:9 aspect ratio.
```
