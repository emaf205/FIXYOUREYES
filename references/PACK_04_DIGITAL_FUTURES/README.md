## Quick start
1. Copy the universal `MASTER_PROMPT.md` (distributed separately).
2. Add one or more transcripts (video, lesson, podcast, or other spoken content).
3. Upload one or more individual reference PNGs from this pack; the atlas is only a selection overview. You may also provide your own images.
4. Add a portrait and corresponding video URLs if desired.
5. Set thumbnail variations **per transcript** (4 transcripts × 2 variations = 8 final images).

The transcript determines the thumbnail's concept, subject and hook. A reference influences the artistic language, not the literal image, text or composition. Text inside each thumbnail must use the **transcript's language**, unless the user explicitly asks otherwise.

**Demo disclaimer:** these images illustrate one fictional seven-day AI-business scenario. Any figures, growth percentages or results shown are invented visual props and must never be represented as measured outcomes.
