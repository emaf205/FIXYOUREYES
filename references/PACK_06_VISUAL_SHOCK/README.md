## How to use
1. Copy the single shared `MASTER_PROMPT.md` from AI YouTube Thumbnail Studio.
2. Upload one or more full transcripts (YouTube video, lesson or podcast).
3. Attach one or more reference PNGs; you may also attach your own style image or portrait.
4. Specify how many distinct thumbnail versions you want **per transcript**. Four transcripts and two versions each means eight separate final thumbnails.

The transcript determines the truthful hook, concept and language. The reference defines the visual style, not the subject matter or layout to copy. Thumbnail text must use the transcript's language unless you explicitly request a different language. Do not reproduce any example figures or outcomes as real claims: this pack's seven-day AI-business video is fictional demo material.
