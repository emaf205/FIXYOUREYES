# PACK 01 — CORE ESSENTIALS

This pack is part of **AI YouTube Thumbnail Studio**.

## What is included
- 1 style atlas: `ATLAS_PACK_01_CORE_ESSENTIALS.png`
- 8 individual style reference images in ``

## Styles included
1. Editorial Illustration
2. Cinematic Drama
3. Minimal Bold
4. Surreal Concept
5. Retro Print
6. Documentary
7. Experimental 3D
8. Pop Graphic

## How to use
1. Copy the main Markdown prompt.
2. Upload one or more video transcripts.
3. Upload one or more style references from this pack.
4. Optionally upload your photo.
5. Specify how many thumbnail variations you want for each transcript.

## Important
- The reference image controls the **style**, not the exact layout.
- If you use the same reference for multiple transcripts, the thumbnails should remain stylistically coherent but conceptually different.
- The text inside the thumbnails should be in the **same language as the transcript**.
