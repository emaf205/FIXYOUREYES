# PACK 03 — ARTISTIC RIOT

A free collection of eight expressive reference images for **AI YouTube Thumbnail Studio**.

## Included
- `ATLAS_PACK_03_ARTISTIC_RIOT.png` — visual index made from the exact eight included references.
- `references/` — eight individual PNG images.

## Use
1. Copy the universal `MASTER_PROMPT.md` (distributed separately).
2. Upload one or more transcripts (YouTube video, lesson, podcast or other spoken content).
3. Upload one or more style references from this pack, or your own references. The atlas is an overview, not a replacement for the individual PNGs.
4. Optionally add a photo and relevant video URLs.
5. Set the number of thumbnails **per transcript** (4 transcripts × 2 variants = 8 images).

Style images guide color, medium and visual language, not the literal scene or text. Every transcript gets its own concepts; each variant must differ meaningfully. Thumbnail text must match the transcript language (unless the user explicitly requests otherwise).

The common seven-day AI-business example and any numerical outcomes shown in these demonstrations are fictional. Do not reuse example results as factual claims in new thumbnails.
